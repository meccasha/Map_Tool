Tools & map sources

Drawing on the map

Brush paints freely; Fill colors a country, province, or visible imported polygon. Drag an Arrow to show movement. Point marks a location. Text adds a note; click an existing note with the Text tool to edit it. Eraser removes one drawing or fill at a time. Borders stay intact.

Use Pan or hold Space while dragging to move. Scroll to zoom. B / F / A / P / T / E / H select tools. Ctrl (⌘ on Mac) + Z undoes; Shift + Ctrl + Z redoes. Save an .atlas project to reopen and edit; a PNG is a flattened image.

Drawings remain visible when switching base maps; region fills keep their original footprint. Use separate projects for separate studies.

Historical subregions

A comprehensive historical province layer is not bundled. Import polygon GeoJSON with its date range and citation. Layers appear only for the matching year when historical outlines are selected and subregions are enabled. Global modern provinces are available with the modern reference map.

Export

PNG exports the view you see, at the chosen resolution, without editor controls. Map geometry and drawings are bundled or stored in your project; no online map service is required.
